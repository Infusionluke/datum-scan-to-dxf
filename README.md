# Datum — Scan to DXF

Windows 11 app that flattens Revopoint **OBJ / STL / PLY** scans into smooth DXF profiles with true circular holes.

## Install / run

1. Download the zip: **Code → Download ZIP** (or use the [release zip](https://github.com/Infusionluke/datum-scan-to-dxf/archive/refs/heads/main.zip))
2. Unzip
3. Double-click **Start Datum.bat**

A Datum window opens. Open or drop a scan, smooth the outline, snap holes, **Export DXF**.

If Windows blocks the script: *More info → Run anyway*.

Works offline. Scans stay on your PC.

Close the Datum window when done, then the small black starter window.
